# WebAPP-RETROTUNED-GARAGE
Офіційний вебсайт дилера ретро- та тюнінгованих спорткарів.

## Проблема, мета та цільова аудиторія
Колекціонерам і поціновувачам ексклюзивних авто складно знайти
надійного дилера з перевіреним каталогом і зручним пошуком.
Мета — зручна платформа перегляду каталогу, бронювання та купівлі авто.
Цільова аудиторія: автоколекціонери, ентузіасти, поціновувачі авто.

## Ролі користувачів
- Гість
- Клієнт
- Адміністратор

## Основні функції та сторінки
Каталог з пошуком і фільтрами, картка авто, обране, заявки та
бронювання, історія покупок, послуги тюнінгу, адмін-панель.
